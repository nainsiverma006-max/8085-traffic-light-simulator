The short version

↗
01

ADD A doubles B. The program loads X into B, moves it to A, then ADD A shifts it left: B becomes 2X outer-loop passes.

02

Nested loops make the delay. Each 65,535-count inner loop costs 1,572,840 T-states; outer-loop overhead brings each pass to 1,572,864.

“Exact” isn't quite exact. At a 6 MHz crystal (3 MHz clock), one pass is ≈0.524 s. So 7 s nominal is 7.34 s actual; 2 s is 2.10 s; 10 s is 10.49 s.

! B is 8-bit: X above 127 overflows when ADD A doubles it.
